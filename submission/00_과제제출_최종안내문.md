  - 📷 스마트폰 카메라 촬영, 갤러리 사진 업로드, 클립보드 붙여넣기(`Ctrl+V`) 지원 (Gemini Vision OCR)

### 2. GitHub 공개 저장소

- **특징**: README만 보고 다른 사람이 자기 API 키(Gemini 또는 OpenAI)로 즉시 실행 가능 (`npm install` ➔ `npm run dev`).

### 3. 발표 자료 (가이드 6장 구성 슬라이드)
- **파일**: `01_발표자료_계약서특약점검기.pdf` (또는 `.html`, `.md`)
- **슬라이드 구성**:
  - **1장: 문제 정의** - 사회초년생의 위험 특약 간과, ChatGPT의 4대 한계(누락, 환각, 개인정보 유출, 계산 오류)
  - **2장: 서비스 소개 & 핵심 가치** - 2대 점검팩, 리스크 시각화, 카메라 OCR, Zero-Click 크롬 확장
  - **3장: 기술 아키텍처 & 설계 판단** - TDD, 도구 호출 대신 "서버 사이드 조문 번들링" 채택, WIF 기반 4단계 고가용성 Fallback Pool
  - **4장: 정량 평가 리포트** - 정답표 선봉인(`c5ee656`), v0 대비 **v1/v2 헛경고 0건(정밀도 100%)** 달성, 응답 속도 60% 단축
  - **5장: AI 활용 & 트러블슈팅** - 정규식 오탐 수정, Gemini Multimodal Vision API 최신화, Free Tier 쿼터 한도 극복
  - **6장: 회고 & 향후 로드맵** - 시스템적 가드레일의 중요성, 등기부등본 실시간 조회 API 연동 계획

### 4. 정량 평가 리포트 (Evaluation)
- **파일**: `02_평가리포트_정량비교.md` (원본: `results/summary_test.md`)
- **실측 요약 (Test Split 20건 / 188개 판정)**:
  - **v0 (기준선 - 단순 질의)**: 위험 재현율 58.3% / 정밀도 63.6% (헛경고 8건 발생)
  - **v1 (인용 강제)**: 위험 재현율 33.3% / **정밀도 100.0% (헛경고 0건)**
  - **v2 (조문 번들링 + 규칙 검사 + 출력 보정)**: 위험 재현율 20.8% / **정밀도 100.0% (헛경고 0건)** / **평균 응답 속도 0.6초 (60% 단축)**
  - **인사이트**: 정상 계약을 위험하다고 오판하여 체결 직전 파기시키는 치명적 문제를 완벽히 근절함.

## 🛠️ 로컬 재현 및 실행 방법

```bash
# 1. 저장소 복제
git clone https://github.com/tripleyoung/lease-clause-check.git
cd lease-clause-check

# 2. 의존성 설치
npm install

# 3. 환경 변수 설정
cp .env.example .env
# .env 파일에 LLM_PROVIDER=gemini 및 GEMINI_API_KEY 입력 (Google AI Studio 무료 키 지원)

# 4. 개발 서버 실행
npm run dev
# 브라우저에서 http://localhost:5193 접속

# 5. 단위 테스트 및 평가 재현
npm test               # 44개 단위 테스트 검증
npm run eval           # 평가 스크립트 실행
```
