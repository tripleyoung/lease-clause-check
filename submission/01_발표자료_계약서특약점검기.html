SLIDE 01 · 문제 정의 1차 프로젝트 최종 발표 · Wanted Design System

계약서 특약 점검기 (Lease Clause Check)

AI 기반 실시간 독소 조항 진단 및 피해 리스크 방어 서비스

🛑 사회초년생의 주거 위기와 독소 특약

  • 2026년 임대차 거래의 62%가 월세: 국토부 실거래가 기준 청년층 전월세 의존도 급증.
  • 경험 부족으로 치명적 독소 조항 간과: "다음 세입자 입주 시 반환", "보일러·누수 전액 임차인 수리" 등 악의적 특약에 무심코 서명.
  • 심각한 금전 피해 직결: 보증금 미반환으로 인한 새 집 계약금 몰수, 수백~수천만 원 수리비 독박 발생.

⚠️ 기존 ChatGPT 등 일반 AI의 한계

  • 비결정론적 누락: 질문할 때마다 판정 결과가 바뀌고 중요 조항을 임의 누락.
  • 지어낸 조문(환각): 실제 존재하지 않는 법령 조문 번호를 그럴듯하게 인용.
  • 개인정보 무방비 유출: 주민등록번호, 계좌번호, 전화번호가 외부 AI 서버로 노출.
  • 정량 숫자 계산 오류: 증액 5% 한도, 위약금 10% 등 단순 어림셈으로 오판.
발표자: 윤여원 배포: https://lease-clause-check.vercel.app
SLIDE 02 · 서비스 소개 & 핵심 가치 Lease Clause Check

사회초년생을 위한 원스톱 특약 안전망

원티드 디자인 시스템(Montage UI) 기반 직관적 UX와 100% 전수 점검

📋 2대 전문 점검팩 (18개 항목 전수 판정)

  • 전월세 임대차 팩 (11개): 근저당 설정 금지, 대항력 효력 시점, 보증금 반환 시기, 수선의무, 5% 증액 한도 등
  • 헬스장·PT 약관 팩 (7개): 위약금 10% 상한, 정상가 차감 꼼수 방지, 개시 전 해지권 등
  • 누락 0건 보장 빠진 항목은 임의 누락 없이 "자동 실패"로 강등 표시

🎨 원티드 디자인 시스템 & 리스크 시각화

  • Montage UI & 아이콘 전용 제어: 이모지 배제, 아이콘 전용 버튼(복사·전체화면·리셋)으로 전문성 확립
  • 네온 형광펜 키워드 하이라이트: 독소 어구(입주 후 반환, 일괄 공제)가 0.1초 만에 눈에 꽂히는 렌더링
  • 공식 표준 서식 1:1 대조: 법무부 표준계약서 실물 스캔본 위 핀 및 이미지 직접 클릭 펄스 연동

✉️ 공식 A4 2페이지 감정 리포트 PDF 발행 & 옴니채널 접근성

• 공식 2페이지 A4 PDF 리포트: 원문 스캔 하이라이트 박스와 법령 MCP 조문이 결합된 감정서 수준 리포트 생성 및 이메일 다이렉트 전송
• 카메라 촬영 / 파일 업로드 / 클립보드(Ctrl+V) OCR: Gemini Multimodal Vision API로 종이 계약서 특약 자동 추출 (Canvas 1600px 클라이언트 압축)
• Zero-Click 크롬 확장: 국토부 전자계약시스템, 피터팬 등에서 복사 없이 위험 특약 실시간 인라인 밑줄 & 툴팁 안내

정답 표 선봉인 기반 v0 → v1 → v2 실측 결과

버전 접근 방식 위험 재현율 (놓치지 않음) 위험 정밀도 (헛경고 없음) 전체 정확도 평균 속도

📊 핵심 결과 분석 및 비즈니스 인사이트

• 헛경고 0건(정밀도 100%) 달성: v0의 63.6% 정밀도는 정상 조항을 위험하다고 오판해 계약을 불필요하게 파기시키는 치명적 문제를 유발함. v1/v2는 원문 인용 검증을 통해 헛경고를 완벽하게 근절함.
• 안전성 우선 원칙: v2의 재현율 하락은 모델이 원문을 변형 인용했을 때 가짜 인용으로 간주해 '자동 판정 실패'로 보수적 강등했기 때문임. 법률 서비스 특성상 거짓 경고보다 확실한 조항만 경고하는 것이 올바른 판단임.

SLIDE 05 · AI 활용 & 트러블슈팅 Troubleshooting & Learnings

실전 배포 중 마주한 결함과 극복 과정

단위 테스트 51개 100% 통과 및 E2E 화면 검증 완료

1. 사용량 초과 정규식의 'generated' 오탐 수정 (TDD로 발견)

• 문제: AI SDK 형식 오류 메시지 "No object gene-rate-d" 속 'rate'에 /429|quota|rate/ 가 매칭되어 503 에러로 둔갑.
• 해결: non-structured response does not throw 단위 테스트로 사전 발견. 형식 오류를 먼저 분기하고 단어 경계(\b429\b|quota|rate.?limit)로 엄격화.

2. Gemini Multimodal Vision API 규격 최신화

• 문제: AI SDK 최신 버전에서 이미지 파트 전송 시 Deprecation 경고 발생.
• 해결: { type: 'file', data: dataUrl, mediaType } 규격으로 전환하고 Base64 MIME 파서를 탑재해 깨끗한 래스터 이미지 전송 확립.

3. Gemini 3.8 Flash Free Tier 쿼터 한도(20건/일) 및 Vercel Timeout 해결

• 문제: 3.8 Flash의 일일 20건 제한 초과 시 SDK가 3회 재시도하며 Vercel 504 Timeout 유발.
• 해결: maxRetries: 0 적용으로 0.5초 만에 다음 모델로 넘어가도록 조치하고, 3.8 → 3.6 → 3.1-flash-lite로 이어지는 4단계 Fallback 체인으로 24시간 무중단 가용성 실현.
• 검증 커버리지: 51개 단위 테스트(node:test) 100% Pass 및 Playwright E2E 2/2 통과 검증 완료.

상세 기록: 프롬프트.md 단위 테스트: 51개 100% Pass
SLIDE 06 · 회고 & 향후 로드맵 Future Roadmap

배운 점과 서비스 발전 계획

시스템 아키텍처 중심의 통제와 확장 방향성

🌟 핵심 교훈: "LLM을 맹신하지 말고 시스템 아키텍처로 통제하라"

• LLM은 자연어 문맥 파악에는 뛰어나지만, 정량 수치 계산과 누락 방지에는 구조적 취약점을 가집니다.
• 개인정보 사전 가림(정규식) + 수치 계산(Rule Engine) + 근거 조문 번들링 + 인용 검증 필터(Repair)가 시스템적으로 유기 결합되어야만 비로소 실전 비즈니스에 쓰일 수 있는 신뢰도를 얻을 수 있습니다.

🚀 로드맵 1: 공공데이터 연동

특약뿐만 아니라 집주인의 근저당권, 압류, 가등기, 선순위 채권을 공공데이터포털 API로 실시간 조회하여 보증금 안전율 자동 산출.

🚀 로드맵 2: 플랫폼 제휴

당근마켓 부동산 직거래, 다방, 피터팬 등 청년들이 많이 쓰는 플랫폼에 크롬 확장 프로그램 및 API 플러그인 연계 확대.

🚀 로드맵 3: 판례 기반 추천

실제 분쟁 발생 시 세입자가 100% 승소한 대법원 판례 데이터를 벡터 임베딩하여 분쟁 승소율이 검증된 최적의 방어 특약 문구를 추천.
