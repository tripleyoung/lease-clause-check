# ClauseGuard 크롬 확장 프로그램 (Zero-Click 인라인 특약 점검기)

전자계약서(국토부 전자계약, 모두싸인 등)나 약관 웹페이지에서 **복사·붙여넣기 없이**, 위험한 특약 조항을 자동으로 찾아 **실시간 빨간 밑줄과 법령 근거, 대안 문구**를 페이지 본문에 직접 띄워 줍니다.

---

## 30초 설치 방법 (크롬 브라우저)

1. 크롬 주소창에 `chrome://extensions` 입력 후 엔터
2. 우측 상단의 **'개발자 모드(Developer mode)'** 스위치를 켭니다.
3. 좌측 상단의 **'압축해제된 확장 프로그램을 로드합니다(Load unpacked)'** 버튼을 클릭합니다.
4. 이 프로젝트의 `extension/` 폴더를 선택합니다.
5. 크롬 툴바에 🛡️ **특약 자동 점검기** 아이콘이 추가됩니다.

---

## 주요 기능

1. **자동 감지 (Zero-Click)**:
   - 페이지 내에 '특약', '임대차', '보증금' 등의 계약 키워드가 감지되면 우측 하단에 플로팅 뱃지가 나타납니다.
2. **실시간 인라인 하이라이트**:
   - `POST https://lease-clause-check.vercel.app/api/check` API와 실시간 통신하여, 불리하거나 위험한 조항에 빨간 물결 밑줄을 그어 줍니다.
3. **법령 조문 및 대안 문구 툴팁**:
   - 빨간 밑줄을 클릭하면 해당 조항이 왜 위험한지(`주택임대차보호법` 등 근거 조문)와 집주인에게 요구할 **표준 대안 문구**(`fix`)를 팝업으로 띄우고 [대안 문구 복사] 버튼을 제공합니다.
